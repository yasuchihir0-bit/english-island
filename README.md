# English アイランド

小学5・6年生向けの、英語を楽しく練習する Web アプリです。
島のマップを1マスずつ進みながら、英語を「聞く・つづる・話す・会話する」練習をします。
勉強するともらえる「ガチャ券」で「なかまガチャ」を引き、動物のなかまを集めます。

インストールは不要で、ブラウザで開くだけで使えます（iPhone の Safari を想定しています）。

> 学校の授業（NEW HORIZON Elementary）の補習を目的に、単元のテーマに近い単語・言い回しを使っています。
> 教科書の本文・イラストは使っておらず、問題文はすべてこのアプリのために作ったものです。
> このアプリは教科書会社とは関係のない、非公式のものです。

## 遊び方

### 🗺️ マップ
島ごとに 6 つのマスがあり、前のマスをクリアすると次に進めます。

| マス | 内容 |
| --- | --- |
| 🔊 聞くマス | 英語を聞いて、合う絵をえらぶ（🐢 でゆっくり再生） |
| ✍️ つづるマス | 文字のタイルを並べて単語を作る |
| 🎤 話すマス | 声に出して言う。マイクで聞き取って判定 |
| 💬 会話マス | 英語の質問に、場面に合う答えをえらぶ |
| 🎁 宝箱マス | 苦手な問題（まちがえた回数が多いもの）を集中トレーニング |
| 🦀 門番ガニ | まとめのバトル。ハート 3 つ |

正解率で ★1〜3（6 割以上でクリア）。何回でもちょうせんできます。

## 学習のしくみ

### 覚えぐあい（単語・表現ごと）
単語 20・文 5・会話 7 の一つひとつに、覚えぐあいを記録しています。

🥚 はじめて → 🐣 聞いてわかる → 🐥 見てわかる → 🐔 言える → 👑 マスター

- 正解すると 1 段階上がり、まちがえると 1 段階下がります。1 日に上がるのは 1 段階までです（その日だけのくり返しで覚えたことにしない）。
- 段階が上がるほど、次に出すまでの日数がのびます（1 日 → 3 日 → 1 週間 → 2 週間）。覚えた問題はたまにしか出ず、苦手な問題はよく出ます。
- 「今日の復習」では、段階に合わせて問題の形が変わります：聞いて選ぶ → 英語を読んで選ぶ → 声に出して言う → つづる。

### 毎日の流れ
1. **🔁 今日の復習**（マップのいちばん上）：わすれかけた問題だけ、最大 12 問。全部終えると +5pt。
2. **🗺️ マップを進む**：まだ覚えていない問題から出ます。
3. **🎰 ガチャ**：ためたガチャ券で引きます。

まちがえた問題は、そのマスの最後にもう一度出ます。

### がんばりポイントとガチャ券
| がんばったこと | ポイント |
| --- | --- |
| 新しい問題に正解 | 1 |
| 復習の問題に正解（思い出せた） | 2 |
| 前の日にまちがえた問題に正解 | 3 |
| 👑 マスターになった | 5 |
| 今日の復習をぜんぶ終えた | 5 |

**10pt でガチャ券 1 枚**。勉強は 1 日 60 分までです（数えるのは問題をといている時間だけ。1 問 40 秒まで）。

数値は `js/app.js` の上のほうにある `POINTS_PER_TICKET`・`PTS`・`INTERVAL`・`DAILY_MIN`・`REVIEW_MAX` で変えられます。

### 🎰 なかまガチャ
- 勉強でためたガチャ券 1 枚で 1 回引けます。**お金は一切かかりません。**
- 出る確率は画面に表示しています（N 60% / R 28% / SR 10% / SSR 2%）。
- なかまが出ると英語の名前が読み上げられます。
- 同じなかまが出たら「かけら」+1。5 こで 1 回むりょう。

### 📖 ずかん
単語・表現ごとの覚えぐあいと、集めたなかまが並びます。なかまを 2 回タップすると、マップにつれていけます。

## 公開のしかた（GitHub Pages）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして Save
3. 数分後に `https://yasuchihir0-bit.github.io/english-island/` で開けます

## iPhone での注意

- 英語の読み上げは iPhone の Safari で使えます。音が出ないときは、消音スイッチ（本体横）を確認してください。
- 発音チェック（話すマス）は **Safari で開いたとき**にマイクを使います。はじめて使うときにマイクの許可を聞かれるので「許可」を押してください。ネットにつながっていないと使えません。
- マイクが使えないとき（ホーム画面から開いたとき・許可しなかったとき など）は、「お手本を聞いて、まねして言えたらタップ」の形に自動で切りかわります。
- 学習の記録はその端末のブラウザの中にだけ保存され、外部には送信しません。
